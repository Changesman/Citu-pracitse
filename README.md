# 词途 · 四级词汇与翻译（Wordway CET4）

背单词 + 背词组 + 四级翻译真题练习，纯前端单文件，可离线运行。

- 2324 个四级核心词（来自《英语四级核心词》PDF），带形近词辨析
- 2033 个常用词组（来自《大学英语四六级常用词组》PDF），带易混搭配
- 20 篇四级翻译：12 篇真题原文（2019–2024）+ 8 篇中国传统文化专题
- **可上传文件 / 粘贴文本导入自己的词语和短语**（txt / csv / tsv / md / json）
- 间隔重复、每日计划、测试、错题本、学习数据

直接双击 `index.html` 使用。

详细说明见 [使用说明.md](使用说明.md)。

## 发布

`index.html` 是唯一需要发布的文件（样式、脚本、全部词库都在里面）。
可以用本目录的 `一键部署到GitHub.cmd` 推到 GitHub Pages。

## 开发

```powershell
node _src/build.mjs      # 由 _src 源码 + CET4 数据生成 index.html
node _src/test-app.mjs   # jsdom 端到端测试
```
